# 陶瓷棋盘音效

原始波形由 render_ceramic.py 合成，44.1 kHz 单声道、16 位 PCM。页面预览 ceramic-preview.wav 按表格顺序播放。

| 事件 | 素材 | 使用时机 |
|---|---|---|
| 选择 | ui-select.wav | 进入玩法、切换棋盘尺寸及确认按钮 |
| 滑动 | tile-slide.wav | 仅棋盘发生变化且没有合并时 |
| 合并 | tile-merge.wav | 每次有效滑动最多一次，用短余振突出落点 |
| 石板 | stone-contact.wav | 障碍阻挡且无法移动时，建议同一手势只响一次 |
| 撤销 | undo.wav | 成功恢复上一手时 |
| 通关 | puzzle-clear.wav | 达成残局、每日目标或本局首次里程碑时，上行三音 |
| 结束 | out-of-moves.wav | 触发无路或步数上限时，下行两音 |

同一步只播优先级最高的提示。连续触发时约束同类音效叠加。合并替代同一次滑动，通关或失败优先于合并。停留、取消和无效滑动保持安静，音效接入时跟随设备媒体音量并提供关闭开关。实机外放听感留待接入后验收。


QA.6 已接入原生 SoundPool。石板触碰根据移动方向扫描到的障碍触发，合并和结束事件优先；其余无效操作保持安静。真机检查七种播放流、音效关闭和暂停/恢复均通过。未改变全局媒体音量；外放主观听感未由人工验收。
