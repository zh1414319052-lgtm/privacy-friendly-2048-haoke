# 青瓷 · 直接设计稿

本轮按用户“直接制作一版设计稿我看看效果”制作。静态可编辑方案，不涉及 Android 应用接入、安装或真机游戏测试。

首页、五种玩法、经典游戏三个页面，加重开确认状态；同一套共享颜色、字体和独立陶瓷素材。文字与数字可编辑，图标、棋盘格和按钮皮肤为独立组件。现有 materials 资源直接复用，build_direct.mjs 是页面布局的源，ceramic-direct.haoke-ui.json 是设计工作台源。

设计尺寸 432×960 逻辑单位，当前画板按 px 存储，导出倍率 2，PNG 为 864×1920。顶部 32、底部 24 为本稿安全区示例；实际 Android 需要按 WindowInsets 适配，不能将本稿系统栏当作应用内容。文字尺寸在实现时映射 sp，触控主入口至少 48 逻辑单位。商用字体 Noto Sans SC，SIL OFL 1.1；字体及许可证附在 preview。

状态：经典 4×4 盘面，示例得分 512、最高分 2048；首页与游戏页一致。重开取消保留本局，确认重置本局、保留最高分。玩法入口保留已有五种模式，不增加联网、排行或账号功能。更多菜单、开始新游戏尺寸选择、各挑战游戏页不在本次三张主页面范围。

验证：四张画板实际导出并整页查看，89 个文字节点无字形/行框溢出；独立成品检查未见错位、遮挡或状态矛盾，卡片规则文案从 11.5 调整到 13，提高手机可读性。原型未连接游戏行为，PNG 不能证明滑动和存档正确。

本方案独立于上一版原图还原稿；用户正在查看新设计，不以此宣称旧参考图已零差异还原。后续如采用此稿，应用须复用这里的组件、参数和素材，在真实安卓截图中验证。


## 2026-11-17 Android 接入

用户批准此稿后完成 QA.6 原生接入；以上静态设计阶段记录保留。Android 从 design.json 读取结构，33 个材质使用原文件。Noto Sans SC 通过 Typeface.Builder 明确 wght 轴；数字使用 36/800 与 (55.875 - 2) / 81.25 的基线映射。系统栏使用实际窗口安全区；横屏增加双栏和深色派生样式，布局集中在 CeramicScene。

字体偏细、数字基线、弹窗测量、下一关安全区和深色导航对比已在真机截图中修正。静态和动态设计源仍保持独立，不用实际截图覆盖原稿。严格 RGBA 比较非零差异，结果和未测边界详见项目根交付说明。

动效：棋盘有效变化 115ms 轻缩放至原尺寸；经典沿用移动 80ms/新块100ms/合并100ms；减少动态效果读取原有 pref_animationActivated。状态和存档在动画前提交。重开取消不改状态、确认重置保留最佳，连续手势以引擎结果为准；真机测试覆盖取消、撤销、重建和返回续局。页面使用 Android 原生导航；离线原型中的 180ms 淡入是设计规格，不能当成原生逐帧验证。浏览器原型 file 协议访问被策略拒绝，本轮未宣称网页动态验收。

字体 API 依据：https://developer.android.com/reference/android/graphics/Typeface.Builder#setFontVariationSettings(java.lang.String)
