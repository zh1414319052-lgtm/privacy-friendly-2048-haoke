# 2048 新玩法

沿用 Android 原生 Java 与现有应用主题，支持竖屏、横屏、触控和键盘。经典 4×4 至 7×7 使用原有存档与统计。本批使用原 QA 包身份，最低 Android 5.0。

| 玩法 | 规则 | 验收 |
|---|---|---|
| 3×3 速玩 | 同数合并、随机出块，目标 256，接着挑战 512 | 3×3 开局、目标提示和进度恢复 |
| 残局挑战 | 固定局面、有限有效步数，无随机出块 | 多种目标，关卡可解，通关或耗尽步数有反馈 |
| 障碍棋盘 | 两块固定石板，滑动按行列分段 | 不能穿过石板，石板两侧可分别合并 |
| 斐波那契 | 1+1 与相邻的斐波那契数可合并，目标 2584 | 测正例、反例和单次合并 |
| 每日挑战 | 按本地日期生成固定局面与目标 | 同一天同题，最少步数独立保存，跨日已打开的局面用原日期 |

新玩法的有效滑动、撤销和重开即时保存。取消确认不改变状态，重开保留历史成绩。单步撤销恢复棋盘、分数、步数及随机状态。存档按模式、关卡或每日日期区分，损坏状态仅影响对应局面。游戏全程离线。视觉素材复用原项目与 Noto Sans SC。
